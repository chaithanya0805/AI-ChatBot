# 🤖 AI ChatBot

A full-stack AI ChatBot application built using **React.js** for the frontend and **Spring Boot** for the backend.  
This project allows users to interact with an AI assistant through a clean and modern chat interface.

---

## 🚀 Features

- 💬 Real-time AI chat interface
- ⚡ Fast Spring Boot backend API
- 🎨 Responsive React frontend
- 🔗 REST API integration
- 🛠 Clean project structure
- 📱 Mobile-friendly UI

---

## 🛠 Technologies Used

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript
- Axios

### Backend
- Spring Boot
- Java
- Maven
- REST API
